# Nitin Kumar — Portfolio

🌐 **Live Website:** [https://nitin.nitinsaini7455.workers.dev](https://nitin.nitinsaini7455.workers.dev)

Professional portfolio website built with Next.js and Tailwind CSS. This repository contains the source for a fast, accessible, and responsive portfolio that showcases projects, experience, education, and contact information.

## Highlights
- Responsive layout and modern UI
- Reusable React components
- Dark mode support
- Optimized for production with Next.js

## Quick Start

Prerequisites: Node.js 18+ and npm

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
npm start
```

## Project Structure

See the `components/`, `pages/`, `data/`, and `styles/` folders for the main application code. Personal content is centralized in `data/resumeData.js`.

## CI
A GitHub Actions workflow is included to run linting and a production build on push/pull-request to `main`.

## Deployment
Recommended: Vercel (first-class Next.js support). You can also host on any Node.js provider using `npm run build && npm start`.
